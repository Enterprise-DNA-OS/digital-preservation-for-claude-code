# Why this is a workbench without a front end

The weekly archive work is an intake queue, integrity checks, copy gaps, rights reviews and preservation actions. The database answers those questions and produces private HTML receipts and reviews. A coding agent runs the commands and explains the results.

A screen adds browsing, image previews, audio and video playback, public discovery, drag and drop and separate user sign-in. This base does not provide those experiences, offline mobile access, automated format conversion or managed cloud storage. Enterprise DNA scopes an access portal, storage integration and conversion tools when building the customer’s version.

The base stores metadata in PostgreSQL or embedded PGlite and originals on disk. It copies and checks bytes without media processing. Never mistake a successful hash check for proof a file is readable, safe or legally shareable. Brand.json controls the name, colours and logo on the three views and three document types. Reports are read-only and private. No web server is required.
