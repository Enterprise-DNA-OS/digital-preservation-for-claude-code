# weekly-review

Prepare Monday from accessions, attention and storage. Name the damaged copies first, then missing content, review owners and this week’s actions.

Run:

```bash
npm run preservation -- weekly-review --json
```

Replace example values with the operator’s facts, including real review dates. Read the result and report the records, reasons and next owner. If a reference is ambiguous, show the candidates and resolve it before any write. Do not send, publish, delete files or change a checksum baseline. Never invent evidence.
Run accessions, attention and storage separately when you need their full detail. The weekly-review command combines the same three results.
